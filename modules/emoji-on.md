Emoji as section cues. One emoji opens each block, so the reader sees its kind at a glance. Use only this map, and always the same emoji for the same kind:

| Block | Emoji |
|---|---|
| The bold result, when the work is done or the answer holds | ✅ |
| The bold result, when the work failed | ❌ |
| The bold result, when the work is blocked | 🛑 |
| The cause, the one sentence on what caused what | 💡 |
| What changed | 🔧 |
| The checks | 🧪 |
| Risks, limits and unverified claims | ⚠️ |
| A recommendation or a choice of yours | 🧭 |
| Docs and memory written | 📝 |
| The "Next:" line | 👉 |

The emoji goes first in the block, before any bold, followed by one space. When section headers are on, it goes in the header instead. A block of another kind gets none. One emoji per block, never inside a sentence, a heading, a table cell, a footnote or code. Every other emoji stays out. This replaces the "No emoji" rule.
