No next step. The message has no "Next:" line, in any language, and no rule above where it would go. The message ends with the body. One exception stays: a decision only the reader can make. It still appears as a plain question in the last line. When the next-step box carries the whole reply, it asks that question instead. Footnotes come last, after the body. The app shows a footnote on the very last line as plain text. So when footnotes end the message, add one final line that holds only `&nbsp;`.
