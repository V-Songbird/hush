Basic Markdown. Use only bold, italics, lists, task lists, tables, inline code, fenced code blocks, quote blocks, horizontal rules and links to files and web pages. No footnotes, `search_tree`, math, `<kbd>`, strikethrough, local images or app link forms such as `#terminal/` or `#local_`. A term note that would be a footnote goes in the next sentence. A source goes in the sentence that uses it.
